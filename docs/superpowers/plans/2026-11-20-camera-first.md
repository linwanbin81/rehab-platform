# 新版真实摄像头跟练实施计划

> 逐项以失败用例、实现和复验推进。当前计划对应重建设计的摄像头优先交付，完整业务流程另行分段实施。

**目标** 从 `8081` 打开新版，使用真实摄像头观察上肢动作，看到关键点骨架、计数和按目标配置计算的分项反馈，能够结束或取消并查看结果。

**架构** Vue 页面调用浏览器媒体设备，先显示视频再加载 MediaPipe。TypeScript 计算即时结果，Java 17 在同源接口上复算关键点并保存 H2 观察记录。摄像头可单独预览和测试。

**技术** Vue、Vite、TypeScript、MediaPipe Tasks Vision、Java 17、Spring Boot、H2。

**设计** `docs/superpowers/specs/2026-11-20-rehab-platform-next-design.md`。

## 约束

- 新目录 `rehab-platform-next/`，`8081` 独立运行。摄像头画面不上传，保存时提交关键点与动作选项。
- 前举、侧举、肘屈伸使用各自机位和二维投影角度。低可靠度、遮挡、多人时不给出达标判断。默认仅观察，目标比较显式填写个人目标。
- 设备拒绝、设备占用、无设备、非安全来源、模型资源加载失败要能区分和重试。关闭或离开时释放轨道。
- 首轮以本机摄像头入口和单组训练记录为交付。计划权限、完整复核和断点续传依原设计续做。

- [x] 先写 `web/tests/motion.test.ts`，用具有已知角度的运动序列检查完整循环、幅度、节奏和遮挡。实现 `web/src/motion.ts` 的二维角度与状态机，Java 用同口径复算。
- [x] 实现 `web/src/App.vue` 训练者工作页面，预览、骨架覆盖、开始与结束、结果及失败提示都有真实行为。通过 Chrome 自动化测试模型资源失败时预览可用，以及视频测试源上真实模型生成骨架。
- [x] 以 HTTP 测试验证保存、复算、读取及错误输入。实现 `server/` 的报告接口和 H2 持久化。
