# 摄像头主线与 BNO055 扩展采购、烧录说明

更新：2026-11-13。本版运行主线是摄像头姿态观察。以下固件是可继续开发的双传感器采集脚手架，尚未通过 Arduino 编译或实物烧录验证，也尚未接入当前训练评价页面。不要把串口能输出四元数等同于关节测量已验证。

## 先运行摄像头版本

| 物品 | 数量 | 选择要求 |
| --- | --- | --- |
| 笔记本内置摄像头或 USB UVC 摄像头 | 1 | 建议 720p 或 1080p，能放置在正面和侧面；应用默认请求 640×480 以降低计算量 |
| 摄像头支架 | 1 | 高度、位置稳定；肩、肘、腕和髋可同时入画 |
| 电脑 | 1 | 能运行 Java、Python、浏览器；模型、WASM 均随项目本地加载 |

无需烧录开发板。先验证三动作的机位、可见性和实际计数表现，再决定是否加入穿戴传感器。

## 如果要做 BNO055 + ESP32

推荐先做一个关节的双传感器实验：**ESP32 DevKitC / ESP32 DevKit V1（ESP32-WROOM-32 / WROOM-32E）一块 + 支持 UART 模式的 BNO055 转接模块两块**。

| 物品 | 数量 | 采购时核对 |
| --- | --- | --- |
| ESP32-WROOM-32 开发板 | 1 | 带 USB 转串口和 BOOT 按钮；确认引出 GPIO16、17、26、27。这里的接线不直接适用于 ESP32-C3、S3 或占用 16/17 作 PSRAM 的 WROVER |
| BNO055 九轴姿态模块 | 2 | 真正的 BNO055，不是 MPU6050、BMP280；须明确引出 PS0、PS1，并能切换到 UART；询问商家供电及 IO 电平。不要买只有不可切换 I²C 接口的封装模块 |
| USB 数据线 | 1 | 与开发板接口匹配，必须能传数据 |
| 杜邦线、排针、试验板 | 1 套 | 按模块焊好排针；固定后再做穿戴实验 |
| 绑带、模块外壳、线缆应力固定件 | 2 套 | 绑带不能压迫肢体；模块不能在皮肤上明显滑动 |

只烧录 **ESP32**。BNO055 自带融合固件，不需要把 `.ino` 烧进 BNO055。电脑通过 USB 供电即可开始桌面实验，暂不增加电池模块。

为什么两块：一块传感器只能观察所在部位相对参考坐标的姿态，不能独立区分上臂、躯干与前臂各自运动。肘部实验分别放于上臂、前臂；肩部实验则分别放于躯干、上臂。若要同时研究肩肘相对运动，需要三块传感器和相应的第三路采集方案，本附带固件只实现两路。

## 双 UART 接线

本固件采用 UART，避免直接照搬 I²C 多地址接法。Bosch 数据手册 §4.5、§4.7、§5.3 规定：PS1=1、PS0=0 选择 UART，通信 115200、8N1。**BNO055 的 SDA/COM0 在 UART 模式是 TX；SCL/COM1 是 RX**。请优先依模块原理图确认名称。

先断电，再按下面接线；两模块均设置 PS1 接模块 3.3V 逻辑高电平、PS0 接 GND，切换后重新上电。ESP32 与模块使用 3.3V IO，不把 5V 接到信号脚。模块供电接其厂商规定的 3.3V 输入；如果模块的 VIN 接法不同，按其说明，不按裸芯片引脚猜测。

| BNO055 引脚 | parent 模块 | child 模块 |
| --- | --- | --- |
| GND | ESP32 GND | ESP32 GND |
| 经确认的 3.3V 电源输入 | ESP32 3V3 | ESP32 3V3 |
| SDA / COM0 / TX | ESP32 GPIO16（RX1） | ESP32 GPIO26（RX2） |
| SCL / COM1 / RX | ESP32 GPIO17（TX1） | ESP32 GPIO27（TX2） |
| PS1 | 3.3V | 3.3V |
| PS0 | GND | GND |

RESET、BOOT、COM2/COM3 等脚依购买模块已有上拉及官方接线要求处理；不要把接口选择脚悬空。这里没有额外接 I²C 多路复用器，也没有用 I²C 地址区分两模块。

## Arduino IDE 烧录

1. 安装 Arduino IDE，在开发板管理器按 [Espressif 官方安装文档](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html) 安装 `esp32 by Espressif Systems`。
2. 打开 `hardware/esp32_bno055_uart/esp32_bno055_uart.ino`。本草图只使用 Arduino ESP32 核心，不需要 Adafruit 库。
3. 开发板选择与实物一致的 `ESP32 Dev Module`，端口选择该板出现的 COM 口。初次建议上传速率 115200。
4. 点击“验证”先编译，再上传。若一直等待连接，按住 BOOT，在连接开始后松开；某些板还需按 EN 复位。
5. 串口监视器设为 115200。启动后每行输出一个 JSON 对象，包含序号、设备时钟、两模块的 `quaternion_wxyz` 和四类校准状态。
6. `ok:false` 或 `quaternion_wxyz:null` 表示读取无效，不应当作零角度。初始化失败后检查线序、PS 模式和供电，修复后复位 ESP32。固件不自动恢复离线模块。

四元数按 Bosch 的 2¹⁴ LSB 规范换算，校准状态为 0～3。输出频率目标约 20Hz；串口超时会使频率下降。两模块顺序读取，分别附有采样时间，不宣称硬件同步。

## 加入训练评价之前必须补的工程工作

- 建立固定安装方向、传感器到肢段的旋转标定、舒适起始姿势标定，并记录每次安装变化。
- 定义 parent/child 关节坐标系。相对四元数可基于 `inverse(q_parent) × q_child` 构建，但须处理坐标约定与安装外参；不能直接用某个欧拉角之差或四元数总旋转量冒充肘屈曲角。
- 实现时间戳同步、丢包标记、校准检查及磁场干扰处理；与参考量角器或其他可靠测量流程比较，报告误差和重复性。
- 再实现串口接收、关节特征、IMU 状态机和入库接口。当前 `/sessions/{id}/capture` 仅接受摄像头关键点，不能把四元数塞入同一字段。
