# 第一版验证记录

验证日期：2026 年 11 月 6 日。运行环境：Windows、Java 8.0.201、Node.js 24.12、Python 3.12.7。默认数据库为 H2 2.2.224 文件数据库。

## 已通过

- Maven 编译与可执行 jar 打包。
- Vue / Vite 生产构建。
- Python 规则测试 3 项：标准动作全部达标；混合演示正确分出幅度、节奏和躯干标签且时间戳唯一；保持要求与幅度关联。
- 真实 HTTP 跨服务联调：登录及注销失效、指导关系隔离、计划参数校验、三动作结果入库、并发完成防重、分项标签、问题事件复核、CSV 导出、计划历史版本、游戏会话关联、管理员数据库概览。
- 一次三动作联调会话形成 18 次动作、9 条问题事件、540 条特征采样；并发完成没有增加重复动作。
- 独立内存数据库故障测试：Python 测试服务返回重复特征时间戳，数据库唯一约束拒绝写入，已插入的组、动作、问题事件全部回滚，会话仍为 RUNNING；更正数据后同一会话正常完成。
- 独立内存数据库并发版本测试：同时调整同一个计划，一个请求成功、另一个被拒绝，只有一个新计划版本。
- 浏览器验证：训练者登录、计划进入、模拟训练、分项报告、点击事件定位、指导者发布计划与保存总体反馈。
- 窄屏验证：390px 布局、移动端退出与角色切换；花朵开合完成一个循环，保存后出现真实互动记录。
- 使用 Windows PowerShell 实际运行双击启动路径；重启后原有计划、报告和复核记录保留。

## 验证边界

MySQL 配置与 MySQL 8 建表脚本已提供，当前电脑没有 MySQL 服务，尚未进行真实 MySQL 联调。动作特征为模拟生成，不是摄像头识别结果；没有 PyTorch 模型精度测试，也没有临床有效性结论。
